# Let's Roll

Demo pages for the Advanced Workbook in Web Application Development (DLBCSWAD01), IU International University of Applied Sciences.

Let's Roll is a **fictional** second-hand marketplace. No real items are sold.

- `task3/` – static HTML listing page (most viewed item) with a linked details page
- `task4/` – responsive Bootstrap 5.3 grid of listings (3 / 2 / 1 columns)
- `task5/` – Vue 3 "Create a listing" form with a live preview (`v-model`), plus a plain-JavaScript comparison

Live site: https://rammi-1one.github.io/lets-roll/
